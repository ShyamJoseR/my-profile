# Shyam Jose R - Personal Portfolio

A personal portfolio website built with a modern tech stack. This project serves as a centralized showcase for professional experience, skills, and projects, featuring a secure admin panel for content management.

## 🚀 Features

- **Modern UI/UX**: Responsive design with liquid layouts, glassmorphism, and smooth animations.
- **Dynamic Themes**: Support for Dark, Light, and Modern themes.
- **Admin Dashboard**: Secure panel to manage profile data, gallery, and skills.
- **Multi-Factor Authentication (MFA)**: Secured using Time-based One-Time Passwords (TOTP).
- **Hybrid Storage**: Local filesystem synchronization with MongoDB Atlas.
- **Image Management**: Integrated with Cloudinary for optimized image hosting.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Atlas)
- **Authentication**: Bcrypt, Speakeasy (TOTP)
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Storage**: Cloudinary API
